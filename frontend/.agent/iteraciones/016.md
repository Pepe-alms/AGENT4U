## Constructor

### 1. Valoración 👍/👎, detrás de una interfaz

`shared/lib/valoraciones.ts` define `RepositorioValoraciones` y una única
implementación sobre `localStorage`. Cuando exista el endpoint bastará con
escribir otra y cambiar cuál se usa: nada del chat sabe dónde se guarda esto.

**La clave es `conversacionId:posición`, no el id del mensaje.** Un mensaje
recién llegado tiene un id local (UUID) que al recargar se sustituye por el
numérico del backend, así que una clave basada en el id perdería la valoración
en cuanto se refrescase la página. Verificado: tras recargar sigue marcada.

### 2. "Regenerar" añade un turno, no sustituye

No es una elección de diseño, es lo que permite el backend: ya ha guardado la
primera respuesta y no hay forma de borrarla ni reemplazarla. Borrarla solo en
la pantalla dejaría la interfaz diciendo una cosa y la base de datos otra.
Dejar las dos a la vista es menos cómodo pero es verdad, y además deja comparar.

### 3. Copiar con referencias

`copiarConReferencias` es una función pura. El texto va tal cual, en markdown, y
las fuentes detrás en una lista **numerada igual que los marcadores `[n]`**, para
que las citas sigan significando algo fuera de la aplicación. El origen solo se
incluye si aporta algo distinto del nombre.
